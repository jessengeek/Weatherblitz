# Weatherblitz ⛈️

A simple, fast weather app. Search for any city and instantly see the current weather.

**🔗 Live Demo:** [weatherblitz.vercel.app](https://weatherblitz.vercel.app) <!-- update if your URL is different -->

![Weatherblitz screenshot](imagess/screenshot.png) <!-- add a screenshot to your images folder and fix this path -->

## Features

- Search weather by city name
- Shows current temperature and weather condition
- Displays humidity and wind speed
- Clean, responsive layout that works on mobile and desktop

## Tech Stack

- HTML5
- CSS3
- JavaScript (Fetch API)
- Weather API (e.g. OpenWeatherMap) <!-- replace with the API you used -->
- Deployed on Vercel

## Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/jessengeek/Weatherblitz.git
   ```
2. Open the project folder
   ```bash
   cd Weatherblitz
   ```
3. Add your own weather API key in the JavaScript code where indicated
4. Open `index.html` in your browser, or use the Live Server extension in VS Code
